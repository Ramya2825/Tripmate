# TripMate – Travel Planner App ✈️

## 📌 About the Project
TripMate is a Flutter-based travel planner application that helps users explore destinations, customize trips, discover places to visit, and plan their travel budget.

## ✨ Features
- Explore popular travel destinations.
- Customize trips based on travel preferences.
- Select trip duration and number of travelers.
- View places to explore at each destination.
- Plan an estimated travel budget.
- Save favorite trips for future reference.

## 🛠️ Technologies Used
- **Flutter** – User interface development
- **Dart** – Programming language
- **Material Design** – UI components

## 📱 Concepts Implemented
- StatelessWidget and StatefulWidget
- Rows and Columns
- GridView and ListView
- CustomScrollView and SliverAppBar
- Navigation using Navigator
- Stateful UI updates using setState
- Images and cards

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:
   ```bash
   cd tripmate
   ```

3. Install dependencies:
   ```bash
   flutter pub get
   ```

4. Run the application:
   ```bash
   flutter run
   ```

## 🎯 Project Objective
The objective of TripMate is to provide a simple and user-friendly interface for planning trips, exploring destinations, and managing travel budgets.
